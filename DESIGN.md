# ML System Design: Movie Recommendation Service

## 1. Цели продукта и постановка задачи

### 1.1. Продуктовая концепция
Минималистичный сервис персональных рекомендаций кино (в эстетике издания «Чтиво») с акцентом на контент, отсутствие рекламного шума и возможность семантического поиска по настроению («по вайбу»).

### 1.2. Пользовательские сценарии (User Stories)
* **Сценарий 1 (Холодный старт / Новый пользователь):**
  У пользователя 0 оценок в профиле. 
  * Поведение системы: 
    1. Полноценная персонализация: учет истории лайков и дизлайков через нейросетевую модель (коллаборативная фильтрация / эмбеддинги).
    2. Двухуровневое ранжирование: быстрый отбор кандидатов + точная сортировка под вкусы профиля.
    3. Добавление блока объяснения («Explainable AI»): почему именно этот фильм рекомендован.


* **Сценарий 2 (Прогретый пользователь / Warm User):**
  В профиле накоплено 5+ оценок.
  * Поведение системы:
    1. Полноценная персонализация: учет истории лайков и дизлайков через нейросетевую модель (коллаборативная фильтрация / эмбеддинги).
    2. Двухуровневое ранжирование: быстрый отбор кандидатов + точная сортировка под вкусы профиля.
    3. Добавление блока объяснения («Explainable AI»): почему именно этот фильм рекомендован.


* **Сценарий 3 (Семантический поиск):**
  Пользователь вводит текстовый запрос («атмосферный неонуар под дождь»).
  * *Поведение системы:
  1. расчет косинусного сходства между эмбеддингом запроса и эмбеддингами синопсисов фильмов, ранжирование по релевантности смыслу.
